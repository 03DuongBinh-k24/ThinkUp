Verification evidence

  • qa/admin-api/ThinkUp-Admin.postman_collection.json ran 34 requests and 36 assertions against an isolated MongoDB replica set.
  • The staging harness performs actual login plus TOTP for SA, CA, CS and FA, then creates a FAQ from the Angular UI, reloads it, compares the API data and deletes it.
  • The local staging CORS allow-list initially rejected the browser origin with ORIGIN_FORBIDDEN. The harness adds its Admin origin before importing Express, and the flow then passes.
  • Public Admin/API deployment remains pending because no shared hosting project or deployment credentials were provided.
