# ThinkUp – Hướng dẫn truy cập hệ thống Demo

<p align="center">
  <strong>Nền tảng học tập trực tuyến ThinkUp</strong>
</p>

ThinkUp gồm hai hệ thống chính: website dành cho học viên (**ThinkUp Education**) và hệ thống quản trị (**ThinkUp Admin**). Tài liệu này hướng dẫn giảng viên, người đánh giá và thành viên nhóm truy cập các bản demo trực tuyến.

## 1. Thông tin dự án

|---|---|
| GitHub Repository | https://github.com/by-nhuanh/ThinkUp |
| Website học viên | https://think-up-edu.vercel.app/ |
| Website quản trị | https://think-up-admin.vercel.app/login |

## 2. Tài khoản Demo

### 2.1. ThinkUp Education – Học viên

| Thông tin | Giá trị |
|---|---|
| Website | https://think-up-edu.vercel.app/ |
| Email | thinkup.edu.vn@gmail.com |
| Mật khẩu | Được cung cấp riêng bởi nhóm phát triển |

**Các bước đăng nhập**

1. Truy cập [ThinkUp Education](https://think-up-edu.vercel.app/).
2. Mở chức năng đăng nhập.
3. Nhập email demo: `thinkup.edu.vn@gmail.com`.
4. Nhập mật khẩu được nhóm cung cấp qua kênh riêng.
5. Đăng nhập để trải nghiệm các chức năng dành cho học viên.

### 2.2. ThinkUp Admin – Quản trị viên

| Thông tin | Giá trị |
|---|---|
| Website đăng nhập | https://think-up-admin.vercel.app/login |
| Email | demo.sa@thinkup.edu.vn |
| Mật khẩu | Được cung cấp riêng bởi nhóm phát triển |
| Xác thực bổ sung | Backup Codes (mã khôi phục 2FA) |

**Các bước đăng nhập**

1. Truy cập [ThinkUp Admin](https://think-up-admin.vercel.app/login).
2. Nhập email: `demo.sa@thinkup.edu.vn`.
3. Nhập mật khẩu quản trị demo được cung cấp riêng.
4. Nếu hệ thống yêu cầu xác thực hai bước, sử dụng một Backup Code hợp lệ theo hướng dẫn trên màn hình.
5. Sau khi xác thực thành công, hệ thống chuyển đến giao diện quản trị.

> **Lưu ý:** Mỗi Backup Code chỉ sử dụng được một lần. Nhóm phát triển cung cấp mã khôi phục qua kênh riêng khi cần thiết. Không đăng tải mật khẩu hoặc Backup Codes trong repository.

## 3. Lưu ý khi trải nghiệm

- Sử dụng đúng tài khoản cho từng hệ thống.
- Đây là tài khoản demo dùng để đánh giá và trải nghiệm sản phẩm.
- Không tự ý thay đổi mật khẩu, thông tin bảo mật hoặc cấu hình tài khoản.
- Không thực hiện thao tác xóa dữ liệu hoặc thay đổi dữ liệu dùng chung nếu chưa được nhóm cho phép.
- Một số chức năng có thể phụ thuộc vào dữ liệu demo và trạng thái triển khai của hệ thống.
- Đảm bảo kết nối Internet ổn định khi sử dụng.
